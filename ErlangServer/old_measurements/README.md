# ErlangServer/old_measurements

Status: **legacy archive**.

## Purpose

Stores older measurement exports, text reports, and earlier result snapshots from the server case study.

## Notes

- These files are preserved for historical comparison and auditability.
- Some files include naming like `copy` from older export steps; they are retained to avoid losing traceability.
- New measurements should be saved in the main `ErlangServer/` area before optional archival.
